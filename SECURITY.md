# Security Policy

## Supported versions

Security support begins with the first Cool Reader Lite release. Until then,
only the latest commit on `master` is considered for security fixes.

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability.

Use GitHub private vulnerability reporting when it is enabled for this
repository. If that channel is unavailable, contact the repository owner through
the contact method published on the GitHub profile at
<https://github.com/miphorez>.

Include affected versions, reproduction conditions, expected impact, and any
proposed mitigation. Do not include real user data or credentials.

## Disclosure

Reports will be acknowledged after review. Publication timing will be agreed
after a fix or practical mitigation is available. The project does not promise a
fixed response time before the first public release.
