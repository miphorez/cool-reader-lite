# Cool Reader Lite color picker icon source

This directory contains the approved pipette master selected from the local
`figma_color_picker_icons` package.

- Source label: `icon:002:pipette`
- Original project: Lucide
- License: ISC
- Approved resource group: `color_picker_icon`

The Android application does not load this SVG directly. The patch generator
rasterizes it into the existing PNG resource name and size.
