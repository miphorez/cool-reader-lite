# Book format icon masters

These SVG masters combine the approved Material `book_6` silhouette with one
format letter in the original `A` field. `FB2` and `FB3` use a smaller raised
digit, with the main `F` shifted left to keep the combined mark centered.
The complete letter group is shifted one unit upward for optical centering.

The generated book silhouette uses a `1.15` outline and 50% more outer padding
than the original filled Material source so it matches the interface icon set.

Regenerate the format masters with `tools/icon_patch/generate_book_format_masters.js`.
