# Cool Reader Lite book icon source

This directory contains the approved open-book master selected from the local
`figma_book_icons` package for the Cool Reader Lite icon patch.

- Source label: `icon:002:book_open`
- Original project: Iconsax by Vuesax, Outline style
- Original license note: GNU GPL v3
- Approved resource group: `cr3_browser_book`

The Android application does not load this SVG directly. The patch generator
rasterizes it into the existing density-specific PNG resource names.
